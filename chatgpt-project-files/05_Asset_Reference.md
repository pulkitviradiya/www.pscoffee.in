## Physical Collateral Guidance

The repo contains website and visual-reference assets, not final print-production files for physical cups, sleeves, bags, uniforms, signage, or packaging. The brand system records those touchpoints as part of the P.S. Coffee identity, but exact production artwork should be pulled from the latest brand-kit export before manufacturing.

Use these rules until production files are available:

- Cups and sleeves use the logo suite only, no added cup/bean/steam illustrations.
- Matte finishes preferred for physical collateral.
- Terracotta is the default coffee/brand face.
- Deep Ceremonial is reserved for matcha or the closing/footer ritual.
- Cream buffer is required between Terracotta and Ceremonial.
- Do not invent new colours, mascots, icon sets, or illustration styles.
