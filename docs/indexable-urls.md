## How to submit this to Google Search Console

1. **Property.** Use the domain property `pscoffee.in` if you can add the DNS TXT record; it covers
   both `www` and the apex in one place. Otherwise use the URL-prefix property
   `https://www.pscoffee.in/` exactly, with the `www` and the `https`.
2. **Sitemaps → Add a new sitemap →** `sitemap.xml`. That one file carries every URL in this
   document. There is no bulk URL submission in Search Console; the sitemap is the bulk path.
3. **URL Inspection → Request indexing**, for the handful that matter most rather than all of them.
   The daily quota is small, so spend it on: the homepage, `/menu`, `/pods`, `/partnership`, the
   three Tier-2 pages, and `/blog/the-letter-and-the-ps-explained`.
4. **Do not** request indexing for the legal pages. They are deliberately absent from the sitemap.
5. Expect nothing for a few days, and partial coverage for a few weeks. "Discovered, not indexed"
   on a new pre-launch domain is normal, not a defect.
