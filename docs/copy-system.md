# P.S. Coffee Copy System

This is the repository copy reference for website work. It captures the supplied **P.S. Coffee
Master Copy System v3.0 (July 2026)** plus later website-specific decisions approved during
implementation. It replaces older copy guidance for this repo; visual treatment remains governed
by [design.md](design.md) and [design-system.md](design-system.md).

## Copy hierarchy

- **W1 — Primary brand truth:** the clearest, shortest expression of the brand idea. Use for hero
  headlines and the single statement a section must leave behind.
- **W2 — Secondary expression:** supports W1 with context, proof, or a sharper product benefit.
- **W3 — Body:** plain, direct explanation in Space Grotesk Body styling. It should read naturally,
  avoid performance, and make the next action clear.
- **W4 — Microcopy:** concise labels, CTAs, form guidance, tags, captions, and status text.

Use the highest available level sparingly. A component does not need all four levels, and copy
must not repeat the same claim at multiple levels.

## Website amendments approved after v3

- Website copy uses **English UK**.
- Do not use em dashes in user-facing website copy. Rewrite with commas, colons, semicolons, or
  full stops according to the sentence.
- Standalone postscript lines use `P.S.:`. Retain the product names **P.S. Coffee**, **P.S. Pass**,
  and **P.S. App** exactly as branded.
- Price data is permitted on the Menu, P.S. Pass cards, and approved homepage hero/menu-preview
  surfaces. The approved homepage statements include “Cappuccino starts from ₹89” and prices in
  “A menu with nothing to hide”.
- Savings language and per-item arithmetic belong only in P.S. Pass contexts. Do not lead general
  brand, Pod, App, About, Join, Partner, or Blog copy with savings.
- Until public launch, use the pre-launch variants from Master Copy v3. Do not imply a live Pod,
  app, service, or availability that has not launched.

## Voice checks

Before shipping copy, confirm that it is direct, specific, and useful; that the strongest line is
not diluted by repetition; that claims can be supported; and that the CTA describes the action the
destination actually provides.
